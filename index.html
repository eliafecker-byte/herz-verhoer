Ein Handy für alle

Funktioniert immer, auch ohne Verbindung: Alle laden ihre Likes auf einem Gerät, ihr ratet laut.

So holst du deine Likes von TikTok
  1. TikTok → Profil → Menü ☰ → Einstellungen und Datenschutz → Konto → Deine Daten herunterladen.
  2. Format JSON wählen, dann «Daten anfordern».
  3. Nach ca. 1–4 Tagen kommt eine Benachrichtigung. Dann innert 4 Tagen herunterladen.
  4. Die ZIP-Datei hier hochladen. Sie bleibt auf deinem Gerät, nur 20 zufällig gewählte Videos gehen ins Spiel.
